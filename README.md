# 🎉 Juwenalia Akademii Tarnowskiej

Strona internetowa poświęcona wydarzeniu **Juwenalia Akademii Tarnowskiej** — corocznemu świętu studentów pełnemu koncertów, wydarzeń kulturalnych i integracji.

---

## 📌 O projekcie

Celem projektu jest stworzenie nowoczesnej i przejrzystej strony internetowej prezentującej harmonogram wydarzeń 📅

Strona ma ułatwiać uczestnikom dostęp do najważniejszych informacji oraz promować wydarzenie w sieci

---

## 🛠️ Technologie

Projekt został zbudowany przy użyciu:

* HTML5
* CSS3 / SCSS
* JavaScript (ES6+)
  
---

## 📂 Struktura projektu

index.html - Główna zawartość strony
style.css - Wygląd strony
script.js - Interaktywna część strony
